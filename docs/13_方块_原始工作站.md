# 方块类 —— 原始工作站

代码位置：`block/` 包、`registry/ModBlocks.java`。

## 1. 敲石台 (knapping_table)
- **获取**：合成 2 泥土 + 4 木板（原始阶段无镐，取圆石需镐，故首配方用泥土）
- **交互（骨架实现）**：手持燧石右键放上工作台 → 空手连续右键敲击
  达到目标次数（3~5）后掉落 3~5 个燧石碎片
- **后续迭代**：打制小游戏 GUI（节点图案）
- **属性**：hardness 2.0，木斧可挖，音效 WOOD

## 2. 篝火坑 (fire_pit)
- **获取**：合成 8 圆石（圆石用任意镐挖取，对齐原版）
- **交互（骨架实现）**：
  - 槽位：0 燃料 / 1 引火物（树皮、树脂、木棍）/ 2 待加热物
  - 放入引火物后用打火石（100%）或钻木取火器（40%）点燃
  - 点燃后光等级 15，燃料耗尽自动熄灭
  - 加热槽内可烹饪物（生肉→熟肉、土豆→烤土豆）每 400 tick 转换
  - 空手右键取回物品；被破坏时掉落内容物
- **属性**：hardness 2.0，不遮挡光照，点燃时冒烟/火粒子

## 3. 晾晒架 (drying_rack)
- **获取**：合成 6 木板 + 2 纤维绳
- **交互（骨架实现）**：手持可晾晒物右键悬挂；右键取回
- **功能**：白天 + 天空可见时晾晒，1 游戏日转换（转换表见 docs/14）
- **属性**：hardness 1.5，非满方块

## 4. 土窑 (pit_kiln)
- **骨架实现**：单方块（正式版为玩家挖 1×1×2 坑、分层填料、泥土封顶的多方块结构，见 docs/14）
- **交互（骨架实现）**：放入燃料（树皮/树脂/干燥纤维/通用燃料）+ 输入（湿陶坯/干陶坯）→ 自动烧制
- **输出**：陶罐；被破坏时掉落内容物，未完成烧制的陶坯按原状态掉落（对齐"进度丢失"原则）
- **属性**：hardness 1.5，音效 GRAVEL

## 5. 简易储物篮 (wicker_basket)
- **获取**：8 植物纤维
- **交互（骨架实现）**：手持物品右键整组放入第一空格；空手右键取回最后放入的一组
- **功能**：9 格容器；被破坏时内容物一并掉落（对齐原版潜影盒逻辑）
- **后续迭代**：正式 GUI、潜行搬走（连内容物）
- **属性**：hardness 0.8，音效 GRASS

## 通用方块属性约定
- 均注册于 `registry/ModBlocks.java`
- 均加入创造标签页 `工业模组：原始时期`
- 含交互方块实现 `EntityBlock` 并挂载 `BlockEntityTicker`
