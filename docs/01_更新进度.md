# 更新进度

按版本倒序记录已完成内容。当前版本：**v0.1.1**（详见 docs/00_版本号.md）。

## [v0.1.1] - 2026-09-17 · 打制小游戏

### 数据组件
- [x] `smod:stone_properties`：石材五维隐藏属性（岩性成分 / 成岩与风化 / 力学与断裂 / 打制性能 / 缺陷与结构），不显示，仅作打制后台参数
- [x] `smod:stone_tool`：石质工具组件（打制度 / 锋利度 / 尖锐度），为后续手柄等扩展预留
- [x] 8 种可打制石材模板（燧石 / 圆石 / 安山岩 / 闪长岩 / 花岗岩 / 凝灰岩 / 深板岩圆石 / 黑石），实例属性按模板 ±10 随机生成

### 打制核心逻辑
- [x] 32×32 打制网格：生成时按「缺陷与结构」在外围 3 层随机缺失（越外侧越容易缺失），自动修复封闭孔洞（禁止打洞型缺失）
- [x] 风化判定：中度 / 重度风化的原石无法放置打制
- [x] 打击：以目标格为中心 5×5 内按力量与工具锋利度移除方格
- [x] 力学与断裂掷骰：崩边（边缘剥落）/ 炸裂（整块报废）
- [x] 成品属性计算：打制度（缺失比例）、锋利度（打制性能 × 岩性上限）、尖锐度（左右上三面轮廓峰值检测）、耐久度（风化/缺陷定基础，三项正面属性最多削弱 15%，写入逐件 MAX_DAMAGE）

### 界面与网络
- [x] 敲石台 GUI：左侧 32×32 网格 + 右侧 5 格打制工具栏 + 玩家背包，纯代码绘制（无贴图依赖）
- [x] 打制工具栏：仅接受打制工具（石质工具组件）或原版石材（粗制工具，锋利度固定 20）
- [x] 交互流程：左键吸附工具到光标 → 长按蓄力（蓄力条三角波循环，速度中等）→ 松开敲击 → 再点工具栏放下（自动吸附最近空槽位）
- [x] 「取出成品」按钮：燧石产出燧石碎片，石材产出打制工具
- [x] C2S 网络包：吸附 / 放下 / 敲击 / 取出，服务端权威校验（距离 + 槽位 + 目标格）
- [x] 网格状态经方块实体 update tag 同步客户端；关闭界面自动归还吸附中的工具

### 物品
- [x] 新工具类别「打制工具」：打制石（KnappingToolItem），Tooltip 显示打制度 / 锋利度 / 尖锐度
