# 配方与获取方式对齐总表

原则：每个新材料的获取必须挂靠原版已有机制。

## 徒手阶段（GameStage 0）
| 材料 | 获取方式 | 对齐的原版机制 |
|---|---|---|
| 植物纤维 | 石刀收割高草丛（原版不掉，本模组加掉落） | 对齐"草丛可被立即破坏" |
| 树脂 | 云杉原木剥皮概率掉落 | 对齐"苹果从橡树掉落"逻辑 |
| 泥土/木板 | 徒手挖掘/合成 | 原版机制 |

## 石器阶段（GameStage 1）
| 材料/物品 | 获取方式 | 对齐说明 |
|---|---|---|
| 燧石碎片 | 敲石台打制；计划：沙砾 25% 掉落 | 对齐沙砾掉燧石 |
| 石质工具 | 打制头 + 组装 | 对齐原版工具合成结构 |
| 树皮 | 石斧右键剥皮 | 完全复用原版剥皮 |
| 黏土球 | 原版黏土块 | 对齐原版 shovel 类挖掘 |
