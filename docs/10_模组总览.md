# 工业模组设计文档 —— 原始时期（Primitive Era）

- 仓库：https://github.com/ODIZUSAZA/zamiuh-s-mod
- 目标版本：Minecraft 1.21.1 Java 版
- 加载器：NeoForge 21.1.249
- ModId：`smod`（Zamiuh's Mod）
- 设计原则：任何新增材料的获取方式都必须与原版逻辑对齐
  （徒手/简易工具可获取、自然生成、生物掉落、农业种植四选一）

## 时代路线图
1. **原始时期**（本文档范围）：石器 + 篝火 + 陶器雏形
2. 铜器时期：铜矿冶炼 → 坩埚 → 铜质机械零件
3. 蒸汽时期：锅炉、传动轴、水车
4. 电气时期：发电机、导线、自动化流水线

## 核心玩法闭环（原始时期）

```
燧石 → 敲石台打制 → 石器工具 → 采集树皮/纤维 → 搭建篝火/晾晒架
     → 挖掘黏土 → 土窑烧制陶器 → 陶坩埚（通向铜器时代）
```

## 代码骨架目录（src/main/java/com/zamiuh/smod）
| 包 | 内容 |
|---|---|
| `SMod.java` | 主类、网络包注册 |
| `registry/` | ModItems / ModBlocks / ModBlockEntities / ModDataComponents / ModMenus / ModCreativeTabs |
| `item/` | ModTiers（工具材料等级）、StoneKnifeItem、FireDrillItem、KnappingToolItem |
| `block/` | 敲石台、篝火坑、晾晒架、土窑、储物篮 |
| `blockentity/` | 对应 5 个方块实体 |
| `component/` | StoneProperties（五维隐藏属性）、StoneToolStats（石质工具组件） |
| `knapping/` | StoneMaterial（石材模板）、KnapGrid（32×32 打制网格） |
| `menu/` `screen/` | KnappingTableMenu / KnappingTableScreen（打制小游戏界面） |
| `network/` | KnappingPayloads（C2S 打制交互包） |
| `client/` | ClientSetup（客户端界面注册） |

## NeoForge 注册要点（1.21.1）
- 注册表：`DeferredRegister.createItems` / `createBlocks` / `create(Registries.BLOCK_ENTITY_TYPE)`
- 创造模式标签页：`DeferredRegister.create(Registries.CREATIVE_MODE_TAB, ...)`
- 数据包配方：`data/smod/recipe/`（1.21 目录为 `recipe`，非 `recipes`）
- 掉落表：`data/smod/loot_table/`（1.21 目录为 `loot_table`，非 `loot_tables`）
- 物品模型：1.21.1 仍使用 `assets/smod/models/item/`（`items/` 定义目录为 1.21.4+ 才引入）
