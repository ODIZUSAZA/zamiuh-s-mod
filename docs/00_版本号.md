# 版本号

## 当前版本
**v0.1.1**（原始时期 · 打制小游戏）

- 同步位置：`gradle.properties` → `mod_version=0.1.1`（发布构建以此为唯一来源）
- 适配：Minecraft 1.21.1 · NeoForge 21.1.249 · Java 21

## 版本规则
采用语义化版本 `主版本.次版本.修订号`：

| 位 | 含义 | 示例 |
|---|---|---|
| 主版本 | 时代跃迁 / 存档破坏性变更 | 0.x 原始时期，1.0 铜器时期首发 |
| 次版本 | 新增功能方块/物品/机制 | 0.1 骨架，0.2 GUI 与事件系统 |
| 修订号 | Bug 修复、平衡性调整 | 0.1.2 |
