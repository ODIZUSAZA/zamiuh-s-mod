- 当前版本：v0.1.0（详见 [docs/00_版本号](docs/00_版本号.md)）

- 设计文档：[docs/](docs/10_模组总览.md)

## 构建与运行
```bash
# 需要 JDK 21 与 Gradle 8.9+（首次运行可执行 gradle wrapper 生成包装器）
./gradlew build        # 构建
./gradlew runClient    # 启动客户端
```

## 玩法闭环
```
燧石 → 敲石台打制 → 石器工具 → 采集树皮/纤维 → 篝火/晾晒架
     → 挖掘黏土 → 土窑烧制陶器 → 陶坩埚（通向铜器时代）
```
